# Blender 控制操作指南

## 1. 检查执行环境

生成或执行 Blender 操作前，先判断执行路径：

- `mcp-live`：存在 Blender MCP 工具，可以检查或修改当前场景。
- `toolkit-live`：存在 Blender Toolkit 或 WebSocket 封装工具。
- `script-only`：没有实时工具；提供用户可自行运行的 Blender Python。
- `blocked`：用户要求实时操作，但 Blender、插件或路径的状态不明。

必须检查：

- Blender 版本（能够获取时）。
- MCP/插件连接状态（能够获取时）。
- 进行破坏性编辑前，先获取当前场景清单。
- 导出或渲染前，确定输出路径。
- 操作是否会写文件、下载素材、使用凭据、清空场景数据或启动长时间渲染。

## 2. 任务分类

每轮选择一个主要类别：

- `scene-inspection`：列出对象、材质、相机、灯光、集合、尺寸、单位和渲染设置。
- `parametric-modeling`：创建或修改基础几何体、容器、盖子、孔洞、加强筋、螺纹、倒角和阵列。
- `material-modifier`：创建或分配材质，设置 PBR 属性，添加修改器，应用或保留非破坏性修改器堆栈。
- `camera-render`：设置相机、转台动画、缓慢变焦、推拉镜头、升降镜头、透明背景和图像序列。
- `export-handoff`：导出 STL、OBJ、FBX、glTF，或准备交付 Three.js / 3D 打印的文件。
- `troubleshooting`：诊断连接、插件、端口、超时、上下文/活动对象和版本 API 问题。

## 3. 参数规则

- 几何结构依赖精确尺寸时，询问缺失的尺寸。
- 明确用户采用的单位制。只有用户要求或意图明确时，产品/工业零件才默认使用毫米。
- 不猜测对象名称；先检查场景或询问用户。
- 保留现有场景时，将生成的对象放入专用集合。
- 用户要求应用到几何体之前，优先保留非破坏性修改器。
- 用于 3D 打印或制造时，说明本技能尚未验证网格有效性、公差、材料和工程审查要求。

## 4. Blender Python 规则

生成的脚本必须：

- 仅导入必要的标准 Blender 模块，例如 `bpy`、`math`、`os` 和 `mathutils`。
- 多步操作后避免依赖 `bpy.context.active_object`，除非脚本刚刚创建该对象。
- 通过明确的名称查找对象；对象不存在时，给出可读的错误信息。
- 写文件前创建输出目录。
- 使用稳定且易读的对象、材质和集合名称。
- 返回或打印简洁摘要，列出创建的对象、输出路径和设置。

生成的脚本不得：

- 未经用户确认就清空整个场景。
- 未经确认就通过宽泛的名称匹配删除已有对象。
- 未经确认就下载远程素材或调用付费 API。
- 使用宽泛的 `except Exception: pass` 隐藏错误。

## 5. 渲染与动画规则

制作相机动画时：

- 先确定目标对象或包围盒中心。
- 使用目标空物体和跟踪约束（Track To），保持相机朝向稳定。
- 需要透明输出时，优先生成带 alpha 通道的 PNG 序列；ffmpeg 可用时再单独编码。
- 长时间渲染需要确认输出路径、分辨率、帧率、时长、渲染引擎和预计帧数。
- 如果渲染可能导致 MCP 调用超时，将帧输出到明确的目录，随后轮询或检查文件。

## 6. 验证清单

至少报告一项可观察的证据：

- 场景清单：对象名称、类型、尺寸和材质名称。
- 修改器堆栈：修改器名称及重要参数。
- 相机/渲染：相机名称、帧范围、帧率、分辨率和透明背景设置。
- 导出/渲染文件：绝对路径；能够获取时，报告文件是否存在及其大小。
- 错误状态：准确的错误信息和下一步诊断操作。
